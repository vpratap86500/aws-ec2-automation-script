# AWS EC2 Automation Script

This project demonstrates how to automate AWS EC2 instance management using Python and boto3.

## Features
- Launch EC2 instance
- Monitor instance state
- Fetch instance details
- Stop instance to optimize cost
- Logging system for tracking actions

## Technologies Used
- Python
- AWS boto3
- EC2

## How to Run
1. Install boto3:
   pip install boto3

2. Configure AWS credentials:
   aws configure

3. Run the script:
   python main.py

## Notes
This script is designed to demonstrate cloud automation using Python and highlights practical usage of AWS services in a real-world scenario.
